# ReWatch — правила для локального ассистента

## Что можно делать
- Мелкие рефакторинги внутри одного файла (переименования, извлечение констант).
- Добавление `aria-label`, `role`, `aria-hidden` к иконкам.
- Генерация изолированных компонентов (Skeleton, Empty, Spinner) по чёткому ТЗ.
- Объяснение кода, разбор ошибок сборки.

## Что НЕЛЬЗЯ делать (без явного запроса)
- Менять дизайн-токены (цвета, шрифты, радиусы, тени).
- Переписывать структуру JSX (`div` → `section`, `flex` → `grid`) без запроса.
- Трогать логику (`useState`, `useEffect`, `onClick`, API-вызовы).
- Заменять компоненты из `@/components/UI` на сырые `<button>`/`<input>`.

## Токены (если всё же нужно)
- Золото: `#E5A93D`, hover `#F2BD5B`, soft `rgba(229,169,61,0.1)`
- Фон: `#0B0E14`, панели `#151921`
- Радиусы: `rounded-3xl` (баннеры), `rounded-2xl` (карточки), `rounded-xl` (кнопки), `rounded-sm` (теги)
- Шрифт: Geist (уже в `--font-geist`)

## Если сомневаешься
Спроси: «Это в одном файле? Это механическая правка?». Если хотя бы один ответ «нет» — предупреди пользователя, что задача не для локальной модели.
