# Чек-лист тестирования сайта MovieTracker

--- 

## Чек-лист тестов страницы авторизации (/login)

### Успешные сценарии

* Ввод username в соответствующее поле
* Ввод email в поле логина (если поддерживается)
* Ввод пароля (отображается в виде скрытых символов)
* Вход с корректными учетными данными
* Перенаправление на главную страницу (/index) после входа
* Перенаправление по параметру next (если указан)
* Корректное сохранение сессии после входа

### Неуспешные сценарии

* Ввод несуществующего username/email
* Ввод неверного пароля
* Пустое поле логина
* Пустое поле пароля
* Оба поля пустые

### Валидация

* Ввод специальных символов в логин
* Ввод слишком длинных значений
* Пробелы в начале и конце логина и пароля (обрезаются)

### UI и форма

* Корректное отображение на мобильных устройствах
* Адаптивность на разных разрешениях
* Placeholder тексты соответствуют полям
* Атрибут required работает
* Вход по нажатию Enter
* Кнопка "Войти" меняет состояние при hover/click

### Навигация и сообщения

* Ссылка "Регистрация" ведет на /register
* Неавторизованный пользователь не видит защищенные разделы
* Отображение сообщений об ошибках
* Авторизованный пользователь не может открыть /login

## Чек-лист страницы регистрации (/register)

### Успешные сценарии

* Регистрация с корректными данными
* Регистрация только с обязательными полями
* Автоматический вход после регистрации
* Редирект на главную страницу

### Валидация полей

**Username:**

* Обязательное поле
* Минимум 3 символа
* Уникальность

**Email:**

* Корректный формат
* Уникальность

**Password:**

* Минимум 8 символов
* Совпадение с ConfirmPassword

### Неуспешные сценарии

* Дублирующий username
* Несовпадение паролей
* Пустые обязательные поля

### Безопасность

* Пароль хранится в хешированном виде
* Отсутствие паролей в логах
* Проверка CSRF-токена
* Серверная валидация всех данных
