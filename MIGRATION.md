# Перенос Python-ветки

Исходная ветка: `testinganother`, commit `cb5e58c475432366b152f81daf6b0e7062cb83b6`.
Основа Laravel/Next.js: `first_laravel-react_test`, commit `a3302f17cf4b91acc9c308b6622d01fee1ff0b63`.

Серверные модели, словари и схема каталога адаптированы из ветки товарища. Вместо Flask/Jinja используется Laravel API с интерфейсом на React/Next.js. Старые Python-файлы доступны в истории Git; для работы сайта они не нужны.

## Два каталога

`/catalog` и `/search` работают с TMDB, включая фильмы и сериалы. Добавление в личный список или коллекцию создаёт локальную запись со статусом `external` и парой `(tmdb_type, tmdb_id)`.

`/library` показывает только `approved`. Заявка сначала получает `pending`. При одобрении модератором уже существующая запись TMDB публикуется с тем же локальным ID, поэтому её оценки, коллекции и прогресс сохраняются. Повторное одобрение не создаёт дубликат. Исправления карточек также проходят модерацию. Отклонение сохраняет причину для автора.

## Импорт

Команда реализована на PHP и открывает источник SQLite только для чтения:

```bash
docker compose exec backend php artisan legacy:import /var/www/legacy/movietracker.db
```

По данным исходной базы перенесено:

| Таблица Flask | Новая таблица | Записей |
| --- | --- | ---: |
| user | users | 50 |
| user_media | entries | 1445 |
| collection | user_lists | 147 |
| collection_item | list_media | 1731 |
| tv_season_progress | season_progress | 564 |
| episode_note | episode_notes | 828 |
| post | legacy_posts | 96 |

Всего создана 3161 ссылка на разные фильмы и сериалы TMDB. `post` в старом приложении не использовалась; её данные сохранены как архив.

Отсутствующий статус переводится в `untracked` («Без статуса»). Статусы `planned`, `watching`, `completed`, `dropped` сохранены; дополнительно доступны отложенные и повторно просмотренные записи.

В исходной БД не было названий и постеров — только ID TMDB. Метаданные подгружаются при показе карточек и кешируются. Пока TMDB недоступен, сохранённые записи видны с ID. В базе есть сгенерированные учебные данные: некоторые ID могут отсутствовать в TMDB. Единственный указанный в базе аватар отсутствовал среди файлов исходной ветки; для него используется заглушка. Существующие файлы `static/uploads` подключаются для чтения.

## Старые пароли

`LegacyUserProvider` проверяет Werkzeug `scrypt` и `pbkdf2:sha256`. Для scrypt PHP вызывает OpenSSL через FFI; пароль не передаётся внешнему процессу. При успешном входе хеш обновляется до bcrypt средствами Laravel. Импорт читает исходные хеши без преобразования и не меняет исходную базу.

## Адреса страниц

| Прежний адрес | Новый адрес |
| --- | --- |
| `/`, `/index` | `/` |
| `/catalog`, `/search?q=…` | Те же адреса, TMDB |
| `/title/movie/ID`, `/title/tv/ID` | Те же адреса |
| `/my_list` | `/entries`, настроен redirect |
| `/collections`, `/collections/ID` | Те же адреса |
| `/stats`, `/profile`, `/profile/edit` | Те же адреса |
| `/forgot-password`, `/reset-password/TOKEN` | Те же адреса |
| — | `/library`, `/media/ID`, `/suggest`, `/moderation`, `/random`, `/persons/ID`, `/public/lists/TOKEN` |

Доступ к личным данным проверяется на сервере по пользователю сессии. Публичные коллекции доступны без входа; смена приватности отзывает прежнюю публичную ссылку.
