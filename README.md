# Rewatch

Дневник фильмов и сериалов: поиск в TMDB, оценки, заметки, прогресс сезонов и личные коллекции. Python-версия из `testinganother` перенесена на PHP/Laravel и React/Next.js. За основу серверной схемы и модерации взята ветка `first_laravel-react_test`.

## Запуск

Нужны Docker с Compose и Node.js 22 для настройки локального запуска. PHP и Composer на компьютере устанавливать не нужно.

```bash
./start-local.sh --build
```

Сайт: **http://localhost:3002**. API: **http://localhost:8081**. Также поддерживается `127.0.0.1`.

Скрипт создаёт приватные `.env`, ключ Laravel и пароль локального администратора, обновляет адреса TMDB для Docker и запускает контейнеры. Для TMDB нужен **API Read Access Token (v4)** в `backend/.env`, параметр `TMDB_API_KEY`. После изменения токена повторите запуск. Логин администратора — `admin`; его пароль находится в `LOCAL_ADMIN_PASSWORD` того же файла.

Если в проекте уже есть `legacy/movietracker.db`, при первом запуске база Flask импортируется автоматически. Повторный запуск сохраняет данные. Остановка:

```bash
docker compose stop
```

Подробнее: [локальный запуск](LOCAL_RUN.md), [перенос данных и функций](MIGRATION.md).

## Возможности

- Еженедельные тренды, поиск и карточки фильмов и сериалов из TMDB.
- Отдельный каталог сообщества: новые карточки и исправления публикуются после модерации.
- Автозаполнение заявки из TMDB: постер, названия, описание, год, жанры, режиссёр, актёры и студии.
- Автор видит статус своих заявок и причину отклонения. Модератор рассматривает все заявки.
- Личный список со статусами, оценками от 1 до 10, датой просмотра и заметкой; фильтрация и сортировка.
- Сезоны и серии, количество просмотренных серий, индивидуальные заметки и оценки серий.
- Коллекции с описанием, обложкой, редактированием, удалением, приватностью и публичной ссылкой.
- Статистика, недавние записи, высокие оценки и продолжение просмотра на главной.
- Профили с аватаром, изменением пароля и восстановлением доступа.
- Случайный фильм из одобренного каталога, актёры, режиссёры и их фильмографии.

## Технологии

| Часть | Стек |
| --- | --- |
| Сервер | PHP 8.4, Laravel 12.72, Sanctum |
| Интерфейс | TypeScript, React 19, Next.js 16, Tailwind CSS 4 |
| База | SQLite, Eloquent, FTS5 |
| Запуск | Docker Compose, Nginx, PHP-FPM, Node.js 22 |

Во взятой за основу ветке фактически использовался Laravel 11. Он обновлён до поддерживаемой версии 12 вместе с зависимостями. Тёмный стиль и бренд Rewatch сохранены. Приложение работает без Flask и Python.

## Проверки

```bash
# Тесты используют собственный контейнер и SQLite в памяти, без тома рабочей БД.
docker compose --profile test run --build --rm --no-deps tests

cd frontend
npm ci --legacy-peer-deps
npm run lint
npm run build
```

Серверные тесты проверяют импорт и совместимость паролей, сессии, модерацию и исправления, приватность коллекций, оценки, прогресс, заметки к сериям, загрузку изображений и одноразовые ссылки восстановления.
