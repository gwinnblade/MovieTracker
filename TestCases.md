# Тест-кейсы для сайта MovieTracker

---

## AUTH - Авторизация и сессии

### TC-AUTH-001

**Название:** Успешный вход по username

**Предусловия:** В БД существует пользователь `user01` с паролем `Pass12345!`.

**Шаги:**

1. Открыть `/login`.
2. Ввести `user01` в поле логина.
3. Ввести `Pass12345!` в поле пароля.
4. Нажать кнопку «Войти».

**Ожидаемый результат:**

* Пользователь авторизован.
* Выполнен редирект на `/index`.
* Отображается flash-сообщение об успешном входе (если предусмотрено).

### TC-AUTH-002

**Название:** Успешный вход по email

**Предусловия:** В БД существует пользователь с email `user01@mail.com` и паролем `Pass12345!`.

**Шаги:**

1. Открыть `/login`.
2. Ввести `user01@mail.com`.
3. Ввести `Pass12345!`.
4. Нажать «Войти».

**Ожидаемый результат:**

* Пользователь авторизован.
* Редирект на `/index`.

### TC-AUTH-003

**Название:** Неверный пароль

**Предусловия:** В БД существует пользователь `user01`.

**Шаги:**

1. Открыть `/login`.
2. Ввести `user01`.
3. Ввести `wrongpass`.
4. Нажать «Войти».

**Ожидаемый результат:**

* Авторизация не выполнена.
* Отображается flash «Неверные данные для входа».
* Пользователь остается на странице `/login`.

### TC-AUTH-004

**Название:** Пустые поля логина

**Предусловия:** Нет.

**Шаги:**

1. Открыть `/login`.
2. Оставить логин пустым.
3. Оставить пароль пустым.
4. Нажать «Войти».

**Ожидаемый результат:**

* Авторизация не выполнена.
* Отображается сообщение о необходимости заполнения полей (клиентская/серверная валидация).

### TC-AUTH-005

**Название:** Редирект по next после входа

**Предусловия:** Пользователь не авторизован. В БД существует `user01`.

**Шаги:**

1. Открыть защищенную страницу, например `/profile`.
2. Убедиться, что произошел редирект на `/login?next=/profile`.
3. Выполнить вход валидными данными.

**Ожидаемый результат:**

* После успешного входа выполнен редирект на `/profile`.

### TC-AUTH-006

**Название:** Выход из аккаунта

**Предусловия:** Пользователь авторизован.

**Шаги:**

1. Открыть `/logout` (или нажать «Выйти» в UI).

**Ожидаемый результат:**

* Сессия завершена.
* Выполнен редирект на главную (или `/login`, по реализации).
* Защищенные страницы требуют повторного входа.

## REG - Регистрация

### TC-REG-001

**Название:** Успешная регистрация только с обязательными полями

**Предусловия:** В БД нет пользователя `new_user_01`.

**Шаги:**

1. Открыть `/register`.
2. Ввести Username: `new_user_01`.
3. Email оставить пустым (если поле необязательное).
4. Ввести Password: `Pass12345!`.
5. Ввести Confirm: `Pass12345!`.
6. Нажать «Зарегистрироваться».

**Ожидаемый результат:**

* Пользователь создан.
* Выполнен автологин.
* Редирект на `/index`.

### TC-REG-002

**Название:** Регистрация - пароли не совпадают

**Предусловия:** В БД нет пользователя `new_user_02`.

**Шаги:**

1. Открыть `/register`.
2. Ввести Username: `new_user_02`.
3. Ввести Password: `Pass12345!`.
4. Ввести Confirm: `Pass12345?`.
5. Нажать «Зарегистрироваться».

**Ожидаемый результат:**

* Пользователь не создан.
* Отображается flash «Пароли не совпадают».

### TC-REG-003

**Название:** Регистрация - username занят

**Предусловия:** В БД уже есть пользователь `user01`.

**Шаги:**

1. Открыть `/register`.
2. Ввести Username: `user01`.
3. Ввести Password и Confirm одинаковые.
4. Нажать «Зарегистрироваться».

**Ожидаемый результат:**

* Пользователь не создан.
* Отображается flash «Такой логин уже занят».

## CATALOG - Каталог

### TC-CAT-001

**Название:** Каталог - переключение type=movie

**Предусловия:** Нет.

**Шаги:**

1. Открыть `/catalog?type=movie`.

**Ожидаемый результат:**

* Отображаются элементы типа movie.
* Пагинация доступна (если есть результаты > 1 страницы).

### TC-CAT-002

**Название:** Каталог - невалидный type нормализуется

**Предусловия:** Нет.

**Шаги:**

1. Открыть `/catalog?type=anime`.

**Ожидаемый результат:**

* Приложение не падает.
* Параметр type нормализуется к `all` (или поведение по умолчанию).

### TC-CAT-003

**Название:** Каталог - невалидный page

**Предусловия:** Нет.

**Шаги:**

1. Открыть `/catalog?page=0`.
2. Открыть `/catalog?page=abc`.

**Ожидаемый результат:**

* Приложение не падает.
* Используется page=1.

## TITLE - Страница тайтла и пользовательские данные

### TC-TITLE-001

**Название:** Доступ к странице тайтла без логина запрещен

**Предусловия:** Пользователь не авторизован.

**Шаги:**

1. Открыть `/title/movie/123` (любое значение).

**Ожидаемый результат:**

* Редирект на `/login` (и next, если реализовано).

### TC-TITLE-002

**Название:** Сохранение статуса просмотра

**Предусловия:** Пользователь авторизован, открыт валидный `/title/movie/<id>`.

**Шаги:**

1. Выбрать статус `completed`.
2. Нажать «Сохранить».
3. Обновить страницу.

**Ожидаемый результат:**

* Статус сохранен и отображается после обновления.

### TC-TITLE-003

**Название:** Ошибка при невалидном статусе

**Предусловия:** Пользователь авторизован.

**Шаги:**

1. Отправить форму со статусом, которого нет в списке (например, через DevTools).

**Ожидаемый результат:**

* Статус не сохраняется.
* Отображается flash «Некорректный статус».

### TC-TITLE-004

**Название:** Сохранение оценки 1-10

**Предусловия:** Пользователь авторизован, открыт тайтл.

**Шаги:**

1. Ввести рейтинг `8`.
2. Сохранить.
3. Обновить страницу.

**Ожидаемый результат:**

* Оценка сохранена и отображается.

### TC-TITLE-005

**Название:** Ошибка при оценке вне диапазона

**Предусловия:** Пользователь авторизован, открыт тайтл.

**Шаги:**

1. Ввести рейтинг `11`.
2. Сохранить.

**Ожидаемый результат:**

* Оценка не сохраняется.
* Отображается flash «Оценка должна быть от 1 до 10».

### TC-TITLE-006

**Название:** TV - сохранение прогресса сезона с ограничением watched

**Предусловия:** Пользователь авторизован, открыт `/title/tv/<id>`, выбран сезон S, у сезона есть N серий.

**Шаги:**

1. Ввести watched = `999`.
2. Сохранить прогресс.
3. Обновить страницу.

**Ожидаемый результат:**

* В БД сохранено watched = N.
* В UI отображается watched = N.

### TC-TITLE-007

**Название:** TV - добавление заметки к серии

**Предусловия:** Пользователь авторизован, открыт `/title/tv/<id>`.

**Шаги:**

1. Выбрать сезон = 1.
2. Выбрать эпизод = 2.
3. Ввести текст заметки.
4. Сохранить.

**Ожидаемый результат:**

* Заметка появляется в списке заметок.
* После обновления страницы заметка сохраняется.

### TC-TITLE-008

**Название:** TV - ошибка при пустой заметке к серии

**Предусловия:** Пользователь авторизован.

**Шаги:**

1. Оставить текст заметки пустым.
2. Нажать сохранить заметку.

**Ожидаемый результат:**

* Заметка не создается.
* Отображается flash «Заметка не может быть пустой».

## COLLECTIONS - Коллекции

### TC-COLL-001

**Название:** Создание коллекции

**Предусловия:** Пользователь авторизован.

**Шаги:**

1. Открыть `/collections`.
2. Ввести название коллекции `Favorites`.
3. Нажать «Создать».

**Ожидаемый результат:**

* Коллекция создана и отображается в списке.

### TC-COLL-002

**Название:** Создание коллекции с пустым названием

**Предусловия:** Пользователь авторизован.

**Шаги:**

1. Открыть `/collections`.
2. Оставить title пустым.
3. Нажать «Создать».

**Ожидаемый результат:**

* Коллекция не создается.
* Отображается сообщение «Название коллекции не может быть пустым».

### TC-COLL-003

**Название:** Добавление тайтла в коллекцию и проверка дубликата

**Предусловия:** Пользователь авторизован. Есть коллекция `Favorites`. Открыт тайтл `/title/movie/<id>`.

**Шаги:**

1. Выбрать коллекцию `Favorites`.
2. Нажать «Добавить».
3. Повторить добавление того же тайтла.

**Ожидаемый результат:**

* Первый раз тайтл добавляется.
* Второй раз отображается сообщение «Уже в коллекции».

### TC-COLL-004

**Название:** Доступ к приватной коллекции для другого пользователя

**Предусловия:** Пользователь A создал приватную коллекцию. Пользователь B авторизован.

**Шаги:**

1. Пользователь B открывает `/collections/<cid>` приватной коллекции A.

**Ожидаемый результат:**

* Доступ запрещен (ошибка/редирект), содержимое приватной коллекции не отображается.
