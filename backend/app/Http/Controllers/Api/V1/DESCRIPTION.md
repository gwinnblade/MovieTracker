# Описание API-контроллеров (app/Http/Controllers/Api/V1)

Слой API проекта — REST-эндпоинты версии **v1**, через которые фронтенд (SPA) общается
с бэкендом. Все контроллеры наследуют базовый `Controller` и возвращают JSON.
Аутентификация — сессионная (guard `web`), авторизованные эндпоинты получают
пользователя через `$request->user()`.

## Общая карта контроллеров

| Контроллер | Назначение | Доступ |
|---|---|---|
| `AuthController` | Регистрация, вход/выход, восстановление пароля | публичный + свой профиль |
| `DashboardController` | Сводка каталога и рекомендации «для вас» | авторизованные |
| `MediaController` | Каталог: поиск, карточка, случайный фильм, похожие | публичный |
| `EntryController` | Записи кинодневника (CRUD) | только свои записи |
| `TrackingController` | Прогресс сериалов: сезоны, серии, заметки | авторизованные |
| `UserListController` | Личные списки/коллекции пользователя | только свои списки |
| `PublicListController` | Публичные списки по ссылке (share_token) | публичный |
| `ProfileController` | Профиль: статистика, топ-жанры, настройка | свой профиль |
| `ModerationController` | Заявки на добавление/редактирование каталога | все + модераторы |
| `PersonController` | Страница персоны с фильмографией | публичный |
| `TmdbController` | Прокси к внешнему API TMDB (поиск, тренды, сезоны) | авторизованные |
| `ReferenceController` | Справочники: типы, статусы, роли, жанры | публичный |

## Аутентификация и профиль

### AuthController — вход в систему
- **register** — регистрация: создаёт пользователя с ролью `user` и темой `dark`, сразу логинит (сессия + регенерация токена).
- **login** — вход по `login` (логин или email — определяется автоматически) и паролю, поддержка «запомнить меня».
- **logout** — выход: инвалидация сессии.
- **me** — текущий пользователь.
- **forgotPassword / resetPassword** — восстановление пароля по ссылке; при сбросе удаляются все активные сессии пользователя (безопасность).

### ProfileController — профиль и статистика
- **show** — витрина профиля: статистика (всего записей, посмотрено, фильмы/сериалы, средняя оценка, просмотренные эпизоды, число коллекций), разбивка по статусам, топ-6 жанров (по SQL-агрегации через `genre_media`), недавняя активность, блок «продолжить просмотр» (статус `watching`) и топ-6 самых оценённых.
- **update** — изменение имени, логина, email, пароля (с проверкой текущего), аватар (загрузка/удаление).

## Каталог медиа

### MediaController — каталог (публичный)
- **index** — список каталога с фильтрами: полнотекстовый поиск (через FTS-таблицу `media_fts`, префиксные матчи `"слово"*`), тип, жанры, диапазон годов; сортировка по дате выхода, названию, средней оценке (`withAvg('entries')`) или дате добавления; пагинация.
- **show** — карточка медиа (с актуализацией данных из TMDB через `MediaLibrary`).
- **random** — «случайный фильм» с фильтрами по типу/жанру.
- **similar** — «похожие фильмы»: ищет режиссёра (`Role` с кодом `director`) и возвращает его другие работы (до 12).

### PersonController — персона
- **show** — страница актёра/режиссёра: фото + фильмография (только одобренные медиа, по убыванию года) с ролью (`role_name_ru`) и именем персонажа.

### ReferenceController — справочники
Отдаёт полные списки справочных таблиц для фильтров и форм: **types** (типы медиа), **statuses** (статусы дневника), **roles** (роли в производстве), **genres**.

## Кинодневник (ядро проекта)

### EntryController — записи дневника
- **index** — список записей пользователя с фильтрами по статусу, типу медиа, «только оценённые», сортировкой по дате добавления или оценке; пагинация.
- **show** — одна запись с медиа и отметками серий.
- **store** — создание/обновление записи (upsert по `user_id + media_id`) в одной транзакции: статус, оценка, дата, заметка + массовое обновление `EpisodeEntry` (отметки/оценки/заметки по сериям).
- **destroy** — удаление записи.

### TrackingController — прогресс сериалов
Работает с моделями `SeasonProgress`, `EpisodeNote`, `Episode`.
- **show** — весь трекинг пользователя по медиа: запись, прогресс по сезонам, заметки к сериям.
- **season** — список серий сезона: для TMDB-сериалов подгружает из TMDB и сохраняет `Episode` в БД (upsert), для локальных — из базы.
- **progress** — «просмотрено N серий из M» по сезону: статус сезона вычисляется автоматически (`planned` / `watching` / `completed`), в транзакции пересчитываются счётчики `episodes_watched` и `seasons_watched` в `Entry`.
- **note** — заметка к конкретной серии (пустая заметка = удалить).

## Списки и публичный шаринг

### UserListController — личные коллекции
- **index / show** — списки пользователя (с количеством медиа) и один список с медиа.
- **store / update** — создание/изменение: имя (уникальное в рамках пользователя), описание, обложка, публичность. При включении публичности генерируется `share_token` (40 символов); при отключении токен **аннулируется**, чтобы старая ссылка не работала.
- **addMedia / removeMedia** — добавление/удаление медиа в список (с датой добавления).
- **destroy** — удаление списка.

### PublicListController — публичные списки
- **show** — список по `share_token` (только если `is_public`) — ссылка, которую можно отправить другу.
- **byId** — список по id: доступен, только если публичный или это чужой список владельца.

## Модерация каталога

### ModerationController — заявка → модератор → каталог
- **index** — заявки: пользователь видит свои, модератор — все (фильтр по статусу).
- **store** — отправка заявки «добавить/изменить» медиа: проверка дублей по TMDB (409, если уже в каталоге или уже есть pending-заявка), загрузка постера, подтягивание данных из TMDB, синхронизация жанров. Внутри транзакции.
- **approve** — одобрение модератором: `lockForUpdate` (защита от гонок), создание/обновление `Media`, применение TMDB-данных, синхронизация жанров, статус `approved`. Всё в транзакции.
- **reject** — отклонение с обязательной причиной (видит автор).

## Интеграция с TMDB

### TmdbController — прокси к внешнему API
- **search** — поиск по TMDB (фильмы/сериалы, пагинация).
- **trending** — тренды TMDB.
- **details** — детали релиза; если медиа уже есть в каталоге — обновляет его данные (`MediaLibrary::apply`) и возвращает локальный `id`.
- **season** — список серий сезона сериала из TMDB.
- **save** — «сохранить в каталог» по TMDB id (создание записи с внешним статусом).

### DashboardController — главная страница
- **summary** — сводка: число медиа в каталоге, пользователей, записей дневника.
- **recommendations** — «рекомендации»: тренды TMDB, из которых исключено всё, что пользователь уже отслеживает (по `tmdb_type:tmdb_id`), до 6 позиций.

## Ключевые сценарии (как контроллеры работают вместе)

1. **Дневник:** `EntryController` создаёт запись → для сериала `TrackingController` ведёт прогресс по сезонам/сериям и заметки → `ProfileController` показывает статистику.
2. **Каталог:** `MediaController` отдаёт каталог с FTS-поиском → `PersonController` — страницы персон → `ReferenceController` — справочники для фильтров.
3. **Модерация:** пользователь находит фильм через `TmdbController` → отправляет заявку (`ModerationController::store`) → модератор одобряет (`approve`) → медиа появляется в `MediaController`.
4. **Списки:** `UserListController` — личные коллекции → `PublicListController` — публичная ссылка для друга.
